1. Create a local directory called first-repo
2. cd into the first-repo directory
3.git init
4.open vscode with 'code .'
5.Create a notes.txt file and take note of the letter u - represents untracked
6. 'git status' - check the status of our local repo
7. 'git add .' - add files
8. 'git commit -m' - describe changes done
9. 'git log' - show who did changes and when 
10. git remote add origin git@github.com:GlenKamau/first-repo-ft19.git
11. 'git remote -v' - show fetch and push 
12. 'git branch -M main' - select the main branch
13. git push -u origin main - create upstream to github
